# 🏫 校园墙

校园综合交流平台，支持表白、投票、聊天等功能。

---

## 📋 功能清单

### 👤 账号系统
| 功能 | 说明 |
|------|------|
| 注册 | 用户名 + 密码 + 昵称 + 真实姓名 |
| 登录 | JWT 认证，7天有效期 |
| 修改密码 | 需验证旧密码 |
| 注销账号 | 阅读须知 + 10秒等待，数据永久删除 |
| 个人资料 | 昵称、真实姓名、性别、自我介绍、班级、毕业信息 |
| 联系方式 | QQ、微信、微博、B站，可选择是否对外显示 |
| 头像上传 | 支持图片上传，自动压缩 |

### 📝 帖子系统
| 功能 | 说明 |
|------|------|
| 发帖 | 支持选择分类（吐槽、分享、求助、讨论、其他）或自定义分类 |
| 匿名发帖 | 不保存用户信息，仅保留IP可追溯 |
| 点赞 | 每人每帖一次 |
| 评论 | 支持文字评论 |
| 搜索 | 按帖子内容搜索 |
| 分类筛选 | 左侧分类栏，支持按话题筛选 |
| 删除 | 作者、管理员、超级管理员可删除 |

### 💌 表白信
| 功能 | 说明 |
|------|------|
| 撰写 | 支持标题 + 内容 |
| 指定收件人 | 按真实姓名搜索 |
| 匿名/实名 | 可选择是否匿名发送 |

### 📊 投票系统
| 功能 | 说明 |
|------|------|
| 创建投票 | 2-10个选项，支持自定义 |
| 投票 | 每人每投票一次，需二次确认 |
| 截止时间 | 可设置投票截止时间 |
| 匿名投票 | 可选择匿名创建 |
| 结果展示 | 实时显示投票数和百分比 |

### 💬 聊天系统
| 功能 | 说明 |
|------|------|
| 好友列表 | 按名字/时间排序 |
| 私聊 | 一对一聊天 |
| 表情 | 48个常用表情 |
| 清空记录 | 一键清空聊天记录 |

### 👥 好友系统
| 功能 | 说明 |
|------|------|
| 添加好友 | 发送好友请求 |
| 接受/拒绝 | 处理好友请求 |
| 删除好友 | 移除好友关系 |
| 拉黑 | 被拉黑者无法发消息 |
| 黑名单管理 | 查看和移除黑名单 |

### 📬 收件箱
| 分类 | 说明 |
|------|------|
| ❤️ 互动 | 帖子被点赞、评论的通知 |
| 📢 公告 | 管理员发布的公告 |
| 💌 表白信 | 收到的表白信 |
| 💬 私信 | 私人消息 |
| 🔔 系统通知 | 系统消息 |
| 操作 | 一键已读、一键删除（支持按分类） |

### ⚙️ 管理后台

**数据统计：**
- 总用户数、活跃用户、封禁用户
- 总帖子数、今日帖子、匿名帖子
- 总评论数、总消息数、今日新用户

**用户管理：**
- 搜索用户（用户名、昵称、真实姓名）
- 修改用户角色（成员/管理员）
- 封禁用户（支持设置时长）
- 删除用户（超级管理员）

**注册审批：**
- 开启/关闭注册审批
- 审批待注册用户

**公告管理：**
- 发布公告（自动通知所有用户）
- 设置置顶
- 设置定时删除
- 删除公告

**话题分类管理：**
- 查看所有分类及帖子数
- 删除自定义分类（帖子移至"其他"）

### 🖼️ 其他功能
| 功能 | 说明 |
|------|------|
| 随机壁纸 | 从 rele 文件夹随机选取，点击按钮换一张 |
| 响应式设计 | 支持桌面端和移动端 |
| 毛玻璃UI | Glassmorphism 风格界面 |
| 查看他人主页 | 点击发帖者头像/名字查看 |

## 🛠️ 技术栈

| 层级 | 技术 |
|------|------|
| 前端 | Vue 3 + Vite + Vue Router + Pinia + Axios |
| 后端 | Node.js + Express |
| 数据库 | SQLite (sql.js, WASM) |
| 认证 | JWT (7天有效期) |
| 样式 | CSS3 + Glassmorphism |

## 🚀 部署方式

### Linux 一键部署

```bash
chmod +x deploy.sh
./deploy.sh
```

### Windows 部署

```bash
deploy.bat
```

### 自定义端口

```bash
deploy.bat --port 8080
```

## 🔐 权限体系

| 角色 | 权限 |
|------|------|
| 超级管理员 | 所有权限，不可删除/封禁 |
| 管理员 | 审批注册、删帖、发公告、管理用户 |
| 成员 | 正常使用所有功能 |
| 待审批 | 无法登录，等待管理员审批 |

## 📡 API 接口

| 路径 | 方法 | 说明 |
|------|------|------|
| `/api/auth/register` | POST | 注册 |
| `/api/auth/login` | POST | 登录 |
| `/api/auth/me` | GET | 获取当前用户 |
| `/api/auth/password` | PUT | 修改密码 |
| `/api/auth/profile` | PUT | 更新资料 |
| `/api/auth/avatar` | PUT | 更新头像 |
| `/api/auth/account` | DELETE | 注销账号 |
| `/api/posts` | GET/POST | 帖子列表/发帖 |
| `/api/posts/:id` | GET/DELETE | 帖子详情/删除 |
| `/api/posts/:id/like` | POST/DELETE | 点赞/取消 |
| `/api/posts/:id/comments` | POST | 发评论 |
| `/api/posts/search` | GET | 搜索帖子 |
| `/api/votes` | GET/POST | 投票列表/创建 |
| `/api/votes/:id` | GET/DELETE | 投票详情/删除 |
| `/api/votes/:id/vote` | POST | 投票 |
| `/api/messages/inbox` | GET | 收件箱 |
| `/api/messages/sent` | GET | 已发送 |
| `/api/messages` | POST | 发送消息 |
| `/api/messages/read-all` | PUT | 全部已读 |
| `/api/friends` | GET | 好友列表 |
| `/api/friends/add` | POST | 添加好友 |
| `/api/friends/block` | POST | 拉黑用户 |
| `/api/friends/unblock` | POST | 取消拉黑 |
| `/api/friends/blocked` | GET | 黑名单 |
| `/api/announcements` | GET | 公告列表 |
| `/api/admin/stats` | GET | 数据统计 |
| `/api/admin/users` | GET | 用户管理 |
| `/api/admin/announcements` | GET/POST | 公告管理 |
| `/api/admin/categories` | GET | 分类管理 |
| `/dashboard` | GET | 后端管理面板 |
