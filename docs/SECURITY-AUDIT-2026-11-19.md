| --- | --- | --- |

| 认证边界 | Router 相对路径及大小写导致聊天封禁绕过；票据用途、类型与版本约束不完整 | 完整路径检查、HS256/claims/audience/version/status 校验；认证 catch 不再吞下游错误 |
| 初始化与离线脚本 | 初始化标志与主体不在同一事务；离线脚本存在固定示例口令及覆盖库行为 | 同事务写初始化标志；离线脚本要求显式输入和新输出，排他创建，不修改线上数据 |
| 墙与好友 | 被封禁者退出后重新加入；blocked 可被 respond/delete 改写 | 保留封禁成员记录、到期结算；严格好友状态转换和双向独立拉黑 |

## 界面与功能

- 统一低饱和青绿亮/暗主题、阅读层级、表面/边框/字体变量；降低壁纸对文字的干扰，保留换壁纸能力。
- 完善移动导航、中间宽度搜索入口、菜单键盘操作、44px 主要目标、跳过导航链接和焦点可见性。
- 修复确认弹窗缺失 ref 导致的焦点失效，嵌套图片预览共享滚动锁；Esc 只关闭顶层，支持恢复触发焦点、输入法及减少动效。
- 加载、空、失败与重试状态区分；公告失败不伪装为空、成功读取后才清未读；Toast 可暂停和关闭。
- 搜索、分类、分页、切帖、切墙、切账户均隔离迟到响应；401 不误清新会话，断网不自动退出，跨标签切墙不改变当前标签请求作用域。

- 评论详情默认 50 条、最多 100 条并提供加载更多；本人新增/删除后重取首屏，避免 offset 重复。
- 聊天离开后停止轮询、路由复用清理、后台暂停、撤回状态刷新、IME 回车保护；收件箱分类已读和删除计数正确。
- 投票截止随时间更新、前后端同时校验截止、客户端传 ISO；权限管理弹窗隔离作用域请求，避免旧结果误授权限。

## 部署与兼容

- 数据根默认仍是 `server/`；设置绝对 `DATA_DIR` 可隔离数据库、JWT 密钥、uploads 和 backups，改变该变量不会自动迁移旧数据。
- 既有库启动时自动增加两列消息隐藏标记；保留原始消息与树洞参与者关系。
- Linux 部署每次按锁文件重新安装依赖并构建，避免旧 node_modules 或 dist 导致安全修复未上线；提供只读预检和仅准备模式。
- nginx 上传路径必须使用本次反代配置，不能继续用旧 alias 绕过证据访问控制；看板保留应用 nonce CSP。安装器安装全部四个 snippet。
- Windows 入口保留 CRLF，统一由 PowerShell 实现版本/端口/进程归属检查；停止操作不再杀其他项目的 Node 进程。
- 未运行实际部署、SSH、防火墙或线上服务修改。现有生产安装必须部署代码与依赖后才能得到这些修复。

## 明确边界与后续运营事项

1. “依赖 0 漏洞”只代表本次公告库扫描结果，不表示系统绝对无漏洞；本轮未对生产地址、操作系统、网络边界或未提供的外部服务做渗透测试。
2. 本机无 nginx、PowerShell 和 ShellCheck，未执行真实 nginx -t 或 Windows 原生运行；已做静态、隔离脚本逻辑和 systemd 验证。
3. 未进行 NVDA/VoiceOver 人工读屏、Safari/Firefox 或实体手机验收，不能据此声称获得 WCAG 认证。
4. 历史示例账号、旧口令及已公开过的证据无法靠代码撤回，需运营方核实旧账号并轮换口令/会话；本轮未读取或更改真实用户数据库。
5. 私密图片票据有效期 5 分钟，过期后刷新列表或页面；不能作为登录 JWT 使用。
6. 旧 bcrypt 超过 72 字节的口令保留历史验证但不自动升级，需本人改密；完全封禁且无原有效票据者仍需管理员联系渠道申诉。
7. 匿名新帖/投票仍沿用不保存作者 ID 的既有隐私语义；旧匿名表白缺失发件人不能可靠回填。
8. 单方隐藏保留服务端数据用于双方记录与会话权限；sql.js 保持单写进程，同一数据文件不应多进程并发写。
9. 仍兼容远程 HTTP(S) 帖子图片，已限制 URL 与 referrer；外部图源仍可接收图片请求。
